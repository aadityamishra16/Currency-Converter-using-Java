# 💱 Currency Converter

A beautiful and intelligent currency converter desktop application built with Java Swing, featuring real-time exchange rates powered by Google's Gemini AI.

![Java Version](https://img.shields.io/badge/Java-11+-blue.svg)
![License](https://img.shields.io/badge/License-MIT-green.svg)
![GUI](https://img.shields.io/badge/GUI-Swing-orange.svg)
![API](https://img.shields.io/badge/API-Gemini%20AI-purple.svg)

## ✨ Features

- 🎨 **Beautiful UI**: Stunning purple-to-orange gradient interface
- 🤖 **AI-Powered**: Uses Google's Gemini AI for accurate exchange rates
- 📊 **Real-time Conversion**: Instant currency conversion with live rates
- 🔄 **Swap Currencies**: Easy swap between "From" and "To" currencies
- 💾 **Offline Support**: Built-in fallback rates when API is unavailable
- 🎯 **Side-by-Side Display**: Amount and result displayed together for easy comparison
- 📱 **Responsive**: Works on different screen sizes
